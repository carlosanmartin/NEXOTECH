# NEXOTECH

Tecnologia que conecta soluciones.

## Descripcion

NEXOTECH es una plataforma de comercio y servicios tecnologicos
desarrollada como proyecto academico de Ingenieria de Sistemas.

El sistema integrara un catalogo de productos, servicios de soporte
tecnico, carrito de compras y un asistente virtual con inteligencia
artificial llamado NEXO AI.

## Ubicacion

Cartagena, Colombia.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js
- Cloudflare Workers
- Groq API
- Git y GitHub
- WordPress para la publicacion final

## Funcionalidades previstas

- Catalogo de productos tecnologicos.
- Servicios de soporte tecnico.
- Carrito de compras.
- Pedidos mediante WhatsApp.
- Chatbot con inteligencia artificial.
- Interfaz responsive.
- Validaciones y controles de seguridad.
